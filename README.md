# escreSer

Site institucional da escreSer, consultoria de escrita de Amanda Plácido Campanha.

## Desenvolvimento
- Vite + React + TypeScript
- Instalar dependências: `npm install`
- Ambiente local: `npm run dev`
- Build: `npm run build`
